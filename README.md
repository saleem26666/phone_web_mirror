# Phone Web Mirror

Mirror phone / Android TV screen to a **PC browser**.  
**No Windows EXE / receiver app.**

## Use

1. Install APK on phone or Android TV  
2. Tap **Start mirror** → allow screen capture  
3. On laptop Chrome/Edge open the address shown, e.g. `http://192.168.2.125:8080`  
4. Fullscreen / Record in the browser  

Same WiFi required.
